# Publish the lo-fi GitHub profile

Your profile README belongs in a **public** GitHub repository whose name exactly matches your username: `BadrELJAOUHARI`.

1. Go to https://github.com/new and create a public repository named `BadrELJAOUHARI`.
2. Upload `README.md`, the complete `assets/` directory, and `.github/workflows/snake.yml` from the ZIP file into the new repository. Keep their folders unchanged.
3. The profile appears automatically at https://github.com/BadrELJAOUHARI. The header GIF animates on GitHub without any external API or service.
4. The contribution snake is an optional little easter egg. To generate it, use **Actions > Animate contribution grid > Run workflow** after uploading. If GitHub says it cannot push to the `output` branch, go to **Settings > Actions > General > Workflow permissions** and enable write permissions if permitted by your account.
5. Pin your favourite repositories directly on your GitHub profile page. Pinning is separate from the README and can't be specified in Markdown.

Notes:
- The design intentionally avoids oversized statistics widgets, badges, fake terminals, and project-card tiles.
- The Cold War repo is described as a tabletop paper prototype, not a software application.
- The CBS research description is high-level and does not include confidential research details.
- Mplus and JAGS are included in the skills table.
- The animated header is derived from an original pixel-art illustration and its text is rasterized, so no custom fonts need to be installed by visitors.

Preview: Open `preview.html` locally to see the layout and artwork. GitHub's exact fonts and borders depend on the visitor's theme and screen size.
